加密密钥和校验密钥是从同一段材料直接切出来的，拿到其中一个就能推出另一个：派生必须带用途标签做域分离；盐与上下文必须参与派生；同一材料不同用途必须得到不同密钥；输出长度必须符合用途要求且不得越界；派生必须确定性；批量派生各用途独立。不变量：任意两个不同用途的输出必然不同；同一输入两次派生结果相同。

## 契约

用途标签只允许来自公开白名单。每次派生都必须把用途标签、盐和上下文一起纳入计算，缺少任意一项都不满足契约。

同一段材料在不同用途下必须得到互不相同的密钥。任意两个不同用途的输出都不允许相等。

输出长度必须落在用途策略允许的闭区间内。低于下限、等于零或高于上限的请求都必须被拒绝，不允许静默截断或返回空结果。

相同输入重复派生必须得到完全相同的字节串。批量派生中每个用途各自计算，互不共享中间值，任一用途的结果都不受其他用途顺序或内容影响。

## 公开接口

仓库提供八个函数：提取、扩展、整体派生、用途标签、长度校验、用途校验、配置校验和批量派生。调用方通过用途名称取得标签，再结合盐与上下文完成派生。

## 配置校验

配置校验返回问题描述列表，覆盖缺少盐、缺少标签以及长度越界。盐除存在性外还必须满足最小长度要求。

## 批量派生

批量请求逐条给出用途、材料与可选长度。返回结果按用途区分，各用途之间必须相互独立。
